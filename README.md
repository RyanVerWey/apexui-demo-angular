# CorvaUI Angular Demo

Public GitHub Pages demo for CorvaUI in Angular.

This app uses `@apexui/web-components` custom elements with Angular `CUSTOM_ELEMENTS_SCHEMA`.
It demonstrates the CorvaUI Concept token family inside a routed mock operations website with home,
analytics, customers, workflows, settings, and about pages.

The demo uses CorvaUI navigation, badges, buttons, cards, charts, DataGrid, Grid, forms, toolbar,
tabs, timeline, workflow board, tree view, empty state, and token-scoped light/dark mode.

While the npm scope is migrating, `@apexui/*@0.1.1` remains the current compatibility line for installs and examples.
